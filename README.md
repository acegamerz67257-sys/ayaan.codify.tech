# Game Night

A static browser version of the original Python games:

- Rock Paper Scissors
- Number Challenge
- Tic-Tac-Toe
- Odd or Even
- Chopsticks
- Footballer Name Challenge
- Atlas
- Footballer Atlas
- Country Capitals

Open `index.html` in a browser to play locally. The site is ready for GitHub Pages: push this repository to GitHub, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Important difference from the Python games

GitHub Pages cannot run a Python/Flask server or maintain a shared server-side leaderboard. This version runs entirely in each visitor's browser. Tic-Tac-Toe is a two-player, pass-the-device game; browser score data is stored locally.
